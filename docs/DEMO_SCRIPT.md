# 3 分钟演示剧本

## 0:00-0:20 开场

“Dating App 让认识人更容易，但没有解决一个更常见的问题：聊天里的兴趣、礼貌、性格和边界混在一起，用户很容易靠猜。”

打开 letsdate：

“letsdate 不做读心术。它把主页和聊天里的信号拆成可验证证据，再给关系判断和下一步动作。”

## 0:20-0:50 输入

点击“载入示例”。

说明：

- 左侧是用户自己的表达。
- 中间是对方主页。
- 下方是双方聊天，明确区分“我”和“对方”。
- 截图入口支持浏览器 OCR。

强调：

“材料由用户主动提供，不需要登录第三方平台。”

## 0:50-1:20 分析

点击“生成关系画像”。

说明处理流程：

1. 提取表达信号。
2. 对齐人格和互动维度。
3. 寻找反证。
4. 生成判断与行动。

## 1:20-2:05 画像与匹配

展示报告首屏：

- 关系判断：适度推进。
- 适配度：74。
- 兴趣信号：72。
- MBTI 候选：ENFP，并保留 INFP、ESFP。

切到“画像与匹配”：

“MBTI 只是一个透镜。这里还有大五人格、互动节奏、能量来源、幽默、冲突线索和边界。”

指出：

“最下方同时分析用户自己在关系里的需要和过度解读风险。”

## 2:05-2:35 证据链

切到“证据链”：

“每一条判断都能回到原话。这里把观察、推断和反证分开，避免把一条消息当成人格定论。”

展示不确定性：

“短期样本不能判断稳定人格，兴趣也仍然需要行动验证。”

## 2:35-2:55 下一步

切到“下一步”：

展示建议消息、对方积极时的动作、对方转冷时的停止条件。

“产品给的是一个可撤回的小行动，不是话术操控。”

## 2:55-3:00 收尾

“letsdate 的核心是一个跨模型 Agent Skill。Web App 是这个协议的第一个产品外壳，后续可以接入平台授权、云端同步和原生 App。”
