# letsdate 项目简介

## 项目名称

letsdate

## 一句话介绍

一个从双方主页和聊天记录中提取可解释关系信号，输出人格假设、互动匹配、兴趣判断和下一步建议的跨模型 Agent Skill 与 Web App。

## 解决的问题

年轻人在小红书和 Dating App 上认识新朋友后，很容易把礼貌、友善、好奇和浪漫兴趣混在一起，也会因为单条消息过度解读人格和想法。现有工具要么只做 MBTI 问卷，要么只分析聊天情绪，缺少同时处理双人互动、证据和不确定性的完整工作流。

## 解决方案

用户输入双方主页、聊天记录和关系阶段。系统先提取事实证据，再使用 MBTI、大五人格和互动行为维度形成假设，并将人格、当前兴趣和关系匹配分开分析。最终报告包含：

- 对方人格透镜与替代类型。
- 用户自身互动位置。
- 双方匹配和兴趣信号。
- 事实、推断、反证和置信度。
- 继续推进、适度推进、先观察或暂缓推进的建议。
- 可直接使用的下一条消息与停止加码条件。

## 技术亮点

- 跨模型 Agent Skill，兼容 OpenAI、DeepSeek、Anthropic、Gemini、Ollama。
- 静态 React Web App，浏览器端 OCR，自带本地演示引擎。
- 结构化 JSON 报告协议，供应商无关。
- GitHub Pages 自动部署与 PWA 基础。
- 默认不上传数据到 letsdate 服务器，API Key 默认只保存在当前会话。

## 差异化

- 不是读心术，输出证据、反证和不确定性。
- 不是单一 MBTI 测试，结合大五人格和互动行为。
- 不是通用恋爱话术，给可撤回的小行动和停止条件。
- 不把关系结果全部归因给一方，同时分析双方互动。

## 后续计划

平台授权导入、云端加密同步、多模态分析、关系时间线、原生 App 上架与心理安全审核。
