# Privacy and Safety

## Data flow

letsdate does not operate a backend for the MVP.

When the user analyzes with a cloud provider:

1. The browser sends the submitted text and skill prompt directly to the provider endpoint selected by the user for fact extraction.
2. A second request sends the verified fact ledger and synthesis instructions to the same provider.
3. The provider may process and retain both requests according to its own policy.
4. The full report is stored in the user's browser history unless cleared.

When the user selects local demo:

- No external model request is made.
- The report is generated by the bundled rule engine.
- History remains in browser storage.

When the user imports a screenshot:

- The image is processed in the browser and is not uploaded to letsdate.
- PaddleOCR may download model files from the official PaddlePaddle model host.
- OCR text is inserted into the local input field for review before analysis.

Emotion and intimacy signal detection uses a local JSON lexicon. Text is not sent to an emotion-analysis service.

Retrieved relationship cases are also processed locally. The bundled library contains anonymized aggregate patterns derived from Apache-2.0 CPED data and fully fictional CC0 dating scenarios. It does not contain raw CPED dialogue, private chats, names or account handles.

## API keys

- API keys are not sent to letsdate.
- Session keys are stored in `sessionStorage`.
- Persistent keys are optional and stored in `localStorage`.
- Users should prefer restricted, revocable keys with spending limits.

## User responsibilities

- Confirm that you have the right to use the submitted material.
- Remove names, phone numbers, addresses, account handles, workplace details and other identifiers.
- Do not upload content involving minors.
- Do not use the tool to monitor, coerce, threaten or manipulate another person.

## Model limitations

- Personality inference from text is probabilistic and incomplete.
- MBTI is not a clinical instrument.
- Big Five estimates from short text are not psychometric scores.
- Attachment-like language is an interaction hypothesis, not a diagnosis.
- Interest signals can be caused by politeness, culture, mood or context.
- Model output may contain errors or hallucinated evidence.

The interface requires evidence excerpts, confidence labels and uncertainty sections to keep these limits visible.

## Safety escalation

The product should not encourage continued pursuit when material shows:

- explicit rejection;
- threats or intimidation;
- stalking or surveillance;
- sexual coercion;
- humiliation or degradation;
- repeated boundary violations.

In these cases, the correct recommendation is to stop contact and seek support from trusted people or appropriate local services.
