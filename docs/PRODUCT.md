# letsdate 产品定义

## 一句话

letsdate 帮助 18-30 岁的年轻人在早期 dating 中，把“我是不是想多了”转化为有证据、有置信度、有行动选项的关系判断。

## 用户问题

用户面对的不是信息太少，而是信号没有结构：

- 主页展示的是对方希望被看见的部分。
- 聊天中的主动性、回应质量和边界反映的是当前互动。
- 礼貌、友好、好奇与浪漫兴趣很容易被混在一起。
- 单条消息和情绪波动会被焦虑放大。
- 用户既想知道“对方是什么样的人”，也想知道“这段关系是否值得继续投入”。

## 产品承诺

letsdate 不承诺知道对方的真实想法，而是承诺：

1. 把事实观察和推断分开。
2. 每个画像结论能够回到具体材料。
3. 同时展示支持证据与替代解释。
4. 把人格倾向、当前兴趣和关系匹配分开处理。
5. 给出自然、有边界、可撤回的下一步动作。

## 核心流程

1. 用户输入双方主页信息、聊天记录和关系阶段。
2. 系统识别材料充分性，提取证据。
3. 分别形成双方 Big Five、MBTI 候选和互动模式假设。
4. 分析双方沟通承接、推进节奏、边界、价值和能量匹配。
5. 单独评估当前兴趣信号。
6. 输出继续推进、适度推进、先观察或暂缓推进的判断。
7. 生成下一步消息和停止加码的边界。

## 目标用户

- 18-30 岁青年男女。
- 使用小红书、Dating App 或社交平台认识新朋友。
- 处于刚匹配、稳定聊天、暧昧、邀约或忽冷忽热阶段。
- 想更清醒地理解互动，而不是学习操控技巧。

## MVP 范围

已实现：

- 文字粘贴与 PaddleOCR PP-OCRv6 中文截图识别。
- 双方主页与聊天记录。
- 本地演示引擎。
- 6 类模型供应商适配。
- 可解释人格画像与证据链。
- 关系匹配和兴趣信号。
- 时间戳、会话、短回复基线与后续恢复。
- 安全、焦虑、回避三类依恋相关互动线索。
- 建议消息、条件分支和停止信号。
- 历史记录、报告导出、隐私设置和 PWA 基础。

暂不在 MVP 内：

- 平台账号登录与自动抓取。
- 服务端数据库与跨设备同步。
- 原生 App Store / 应用商店上架。
- 真实心理量表或临床评估。

## 差异化

GitHub 上已有文本人格预测、微信聊天分析和 MBTI 问卷项目，但多数只覆盖单一环节。letsdate 的差异不是“又一个 MBTI 测试”，而是：

- 主页与聊天双源输入。
- 用户与对方双人视角。
- 人格、兴趣、匹配三件事分开。
- 事实、推断、反证和置信度分层。
- 供应商无关的 Agent Skill 与 Web App 复用同一协议。

## 北极星指标

用户完成一次分析后，能够明确回答：

1. 当前最值得观察的信号是什么？
2. 哪些判断证据不足？
3. 下一步做什么，以及在什么条件下停止？

## 后续产品路径

1. Web 公测与真实用户访谈。
2. 平台授权导入、权限透明化和云端加密同步。
3. 关系时间线与变化趋势。
4. 语音、图片与视频多模态。
5. 原生 App 与更严格的内容安全、心理危机干预机制。
